# 6. Tiered Prepaid Naira AI Token Billing

We decided to implement an opt-in prepaid Naira wallet for standard Tier 2 clients, while bundling a starter AI token quota into Tier 1 mid-market subscriptions.

Nigerian merchants face extreme currency volatility when billed directly in USD for third-party AI APIs. A local Naira wallet with deterministic per-token drawdowns insulates merchants from FX shocks and prevents unexpected overages.

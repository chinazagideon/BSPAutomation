# 4. Swappable Payment Adapter with Moniepoint MFB Primary Rail

We decided to implement a swappable payment gateway adapter interface with Moniepoint Microfinance Bank (MFB) dedicated virtual accounts as the primary default rail.

Nigerian SMEs rely heavily on direct bank transfers via USSD and mobile apps. Moniepoint MFB offers instant credit alerts and low latency webhooks. The swappable adapter allows adding Paystack DVA or Flutterwave without modifying the core checkout ledger.

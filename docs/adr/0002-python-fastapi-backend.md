# 2. Python FastAPI & AsyncIO Core Backend

We decided to build the core backend services using Python with FastAPI, Pydantic, and AsyncIO.

Python provides native runtime compatibility with local NLP tokenizers (spaCy, Rasa, custom Nigerian Pidgin rule engines), LangChain/Gemini LLM integrations, and strict deterministic Pydantic data modeling for double-entry financial ledger invariants.
